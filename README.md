# Surecomply Services

Public website source for Surecomply Services: website setup, document formatting, and digital design.

## Status

The website includes owner-provided contact details and a confirmed business address. The owner should review the proposed services and customer policies before submitting it to Razorpay. Creating or publishing this website does not establish Razorpay approval.

## Pages

- Home and about
- Services and quote-based INR pricing
- Contact
- Terms and conditions
- Privacy policy
- Refund and cancellation policy
- Digital service delivery policy

## Build

Requires Node.js. No packages need to be installed.

```sh
npm run build
```

The static website is generated in `dist/`. Update `business.json`, `styles.css`, and `scripts/build.mjs` to edit the content, then rebuild.

## Hosting

Use hosting suitable for a business website. The repository contains the website source; its GitHub repository URL is not the business website URL. GitHub Pages is not used because of its restrictions on hosting an online business.

## Owner review

Proposed offerings: simple website setup, document and presentation formatting, and digital graphics. Pricing is by written quote. Timelines and revision allowances are agreed per project. The proposed refund policy allows a full service-fee refund before work starts and a refund of the unused portion after work starts, with approved refunds initiated within 7 business days. Confirm that these terms match the business before submitting the website.

Only public contact details belong in this repository. Never add credentials, customer records, identity documents, or payment information.
